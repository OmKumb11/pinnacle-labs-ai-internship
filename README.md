# Pinnacle Labs AI Internship Projects
## 🌍 Translator App
AI-powered translation app built with Streamlit and Deep Translator.
### How to run:
pip install streamlit deep-translator
streamlit run translator_app.py


## ✍️ Autocorrect Tool
AI-powered autocorrect tool built with Streamlit and TextBlob.
### How to run:
pip install streamlit textblob
streamlit run autocorrect_app.py
